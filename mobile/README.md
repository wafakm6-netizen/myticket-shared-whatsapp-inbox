# Myticket Inbox app (iPhone & Android)

Capacitor 8 shell around https://whatsapp.myticketom.com. See **docs/mobile-app.md** for building on the
Mac and sharing the app privately (TestFlight internal testing, Play Console internal testing).

```bash
npm install
npx cap sync
npx cap open ios       # Xcode
npx cap open android   # Android Studio
npm run assets         # regenerate icons/splash from assets/
```
